# Garment cut-out assets

Transparent-background (RGBA PNG) garment cut-outs bundled for the demo
wardrobe, referenced by `processedImageUrl` in `lib/state/wardrobe_state.dart`
→ `_demoSeed()`. Most demo pieces load real catalog photo URLs directly; this
folder holds the cut-outs that need to be bundled instead of hotlinked.

## Current files

- `scarf.png` — the Cashmere Scarf, background-removed with the free
  `not-lain/background-removal` HF Space (AI segmentation) so it renders as an
  isolated product shot on the neutral card. Generated by `tool/cutout_scarf.py`.

## Format

- **Transparent PNG**, garment centred, ≤ ~720px. `ItemImage` mats any
  `assets/…` path `BoxFit.contain` with ~10% padding on the neutral card, and
  falls back to a colour silhouette if the asset is missing.

## Regenerating / adding

```bash
python tool/cutout_scarf.py <image_url> assets/garments/<name>.png
```

Drop a real transparent product PNG over any of these to swap it. Anything under
`assets/garments/` is auto-bundled via the `assets:` entry in `pubspec.yaml`.
